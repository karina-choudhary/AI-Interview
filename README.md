# AI Interview Platform

An AI-powered interview platform that helps users practice interviews and receive personalized feedback on their answers using Google Gemini AI.

## Features

- **AI-Powered Feedback:** Evaluates submitted interview answers and generates feedback using Google Gemini AI.
- **User Authentication:** Supports user authentication and protected features.
- **Interview Practice:** Provides an interface for users to participate in interview sessions.
- **REST API:** Backend APIs built with Node.js and Express.js.
- **Database Integration:** MongoDB for storing application data.
- **Responsive UI:** Frontend developed using React and Tailwind CSS.

## Getting Started

1. Clone this repository.
2. Install the required dependencies in the relevant project folders.
3. Configure the required environment variables in a `.env` file.
4. Start the frontend and backend using the scripts defined in their respective `package.json` files.

## Environment Variables

Add the required configuration values to your local `.env` file. These may include database connection details, authentication secrets, and your Gemini API key, depending on your implementation.

**Important:** Never commit API keys, passwords, or other secrets to GitHub.
